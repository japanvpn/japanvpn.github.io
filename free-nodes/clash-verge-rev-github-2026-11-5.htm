什么是Shadowrocket？

Shadowrocket是一款iOS平台上的网络代理工具，专门为用户提供科学上网服务。它支持多种代理协议，如Shadowsocks、Vmess、Trojan等，能够有效帮助用户突破网络封锁，访问被限制的网站。无论是需要全局代理，还是希望自定义规则来灵活控制哪些流量走代理，Shadowrocket都能满足各种需求。

Shadowrocket的主要功能

1. 全局代理模式

Shadowrocket的全局代理模式允许用户将所有网络流量通过代理服务器转发。这意味着，您在使用任何应用时，所有网络请求都会自动通过代理进行加密和转发，从而实现科学上网。这一功能对于需要访问被封锁网站的用户来说至关重要。

2. 多种协议支持

Shadowrocket支持多种代理协议，包括Shadowsocks、Vmess、Trojan等。这些协议各具特色，用户可以根据需要选择最适合的协议。例如，Shadowsocks以其轻量、快速而受到广泛青睐，而Vmess协议则在隐私保护和抗干扰方面表现出色。通过支持多种协议，Shadowrocket能够提供更加灵活和高效的上网体验。

3. 自定义规则设置

Shadowrocket的自定义规则设置是其一大亮点。用户可以根据自己的需求设置访问规则，灵活地控制哪些流量走代理，哪些流量直连。例如，您可以设置某些特定的网站（如社交媒体平台）走代理，而其他网站（如新闻网站）则直接连接。这一功能为用户提供了更高的灵活性和控制权。

4. 流量统计与监控

为了帮助用户更好地管理网络流量，Shadowrocket还提供了实时流量监控和统计功能。用户可以查看各个应用的流量使用情况，实时掌握网络使用状况。通过这一功能，用户能够有效优化流量的使用，避免出现不必要的数据浪费。

配置完成代理服务器后，用户可以在Shadowrocket的主界面中选择刚才添加的代理配置。点击“全局模式”，此时，所有网络流量都会通过代理服务器进行转发。这一模式适合需要在所有应用中使用代理的用户，例如需要访问被墙网站时。

FAQ

SSR 的协议参数和混淆参数如何配置最安全？
选择 AEAD 或协议插件可提升安全性，混淆方式如 tls1.2_ticket_auth 可以模拟正常 HTTPS 流量。合理搭配协议和混淆参数，能够有效抵御 DPI 检测和流量封锁。
Mihomo 节点分组如何保证低延迟访问？
将节点按延迟、地区或用途分组，并启用策略组，系统会根据节点健康和延迟自动选择最佳节点。保证网页浏览、视频播放和游戏流量的低延迟稳定连接。
Trojan-Go 的多路复用（mux）如何开启？
Trojan-Go 在配置文件中通过启用 mux 参数即可实现多路复用。此功能允许多个连接共享同一隧道，减少握手延迟并提升整体传输效率，尤其在移动网络中表现出色。
Hysteria2 多路复用如何优化短连接性能？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适用于游戏、即时通讯等高频短连接场景，提高吞吐量和连接稳定性，优化整体网络体验。
Surfboard 策略组如何提升游戏和视频体验？
通过策略组将游戏、视频和浏览器流量分配到低延迟、高带宽节点，Surfboard 可自动切换最优节点，减少延迟和卡顿，提高整体网络体验和访问速度。
PassWall2 能运行在哪些设备上？
PassWall2 是基于 OpenWRT 的插件，只要路由器支持该固件，就能安装运行。常见型号如小米路由、斐讯、软路由都可以使用，通过 Web 界面操作，适合家庭网络使用场景。
Sing-box 的路由规则能否实现分国家代理？
Sing-box 支持 GeoIP 路由规则，通过引入国家数据库可根据 IP 自动判断地理位置。例如可设置 CN 走直连，US/JP 走代理，以此实现分国家策略路由，适合需要访问不同地区内容的用户。
Hysteria2 的多路复用如何提高传输效率？
Hysteria2 利用 QUIC 的多路复用功能，将多个请求共享单个 UDP 连接，减少握手次数和延迟，提升整体吞吐量。尤其在高并发场景中效果显著。
Nekoray 与 Nekobox 有什么区别？
Nekoray 是基于 sing-box 的多平台代理客户端，支持 Windows、Linux 等系统；而 Nekobox 则是为 Android 设计的移动版本。两者共享相同的核心逻辑，均支持 VMess、VLess、Trojan 等协议，适合跨设备同步使用。
Netch 的 TCP/UDP 分流适合哪些应用？
TCP 分流适合网页、下载和视频播放，UDP 分流适合游戏、语音和实时视频。Netch 可同时代理 TCP 和 UDP 流量，实现精准分流，保证不同应用的最佳性能。
