一、小火箭简介：iOS用户的自由之门

“小火箭”并不是官方名称，而是Shadowrocket这款iOS端代理应用的中文昵称。作为一款功能齐全的网络代理客户端，小火箭支持的协议非常全面，包括：

  • Shadowsocks（SS）

  • ShadowsocksR（SSR）

  • Vmess / VLESS

  • Trojan

  • HTTP / HTTPS

  • SOCKS5

这意味着只要拥有正确的节点配置，你几乎可以实现对全球任意网络的访问。而小火箭最被用户津津乐道的地方在于：强大的规则系统、稳定的连接性能以及对V2Ray协议的良好支持。

二、Vmess协议概述：为何越来越多人选择它？

在V2Ray项目中，Vmess协议的设计目标就是打破传统Shadowsocks在深度检测中的弱点，提供更安全、抗干扰的代理能力。它具备以下几个优势：

  • 数据加密与认证：相比Shadowsocks，Vmess的数据包自带认证机制，可有效防止流量重放与伪装攻击。

  • 多种传输层支持：可通过TCP、WebSocket、HTTP/2等方式传输，甚至搭配TLS混淆，进一步增强隐匿性。

  • 配置灵活性高：支持更多参数自定义，比如UUID身份识别、动态端口、Header伪装等。

这些特点让Vmess成为在高干扰环境下依然能保持畅通连接的理想选择。

三、开始之前：你需要准备什么？

在正式配置Vmess前，你需要准备以下内容：

  1. 已安装的小火箭客户端（来自海外Apple ID的App Store购买，或越狱方式安装）

步骤二：添加Vmess节点到小火箭

方法一：自动导入

  1. 复制vmess链接

  2. 打开小火箭，点击右上角“+”

  3. 选择“从剪贴板导入”

  4. 小火箭会自动识别并生成配置，点击“完成”即可添加成功

方法二：手动输入

适用于手动获取节点信息时，步骤如下：

  1. 打开小火箭，点击右上角“+”

  2. 协议选择“Vmess”

  3. 填入以下关键信息：

    • 地址（Address）：服务器域名或IP

    • 端口（Port）：服务端口，常见如443

    • 用户ID（UUID）：服务商提供的唯一用户识别码

    • 额外ID（alterId）：部分服务设定为0，已废弃可留空

    • 加密方式：推荐使用auto或aes-128-gcm

    • 传输协议：TCP或WebSocket（ws）

    • TLS：如节点支持，务必启用以提高隐私

    • 伪装路径（path）：如使用ws协议，则需填写路径，如/path

    • Host：伪装域名或cdn域名

  4. 配置完成后，点击“保存”

步骤三：启动并测试连接

  • 返回小火箭首页

  • 选择刚添加的Vmess配置

  • 点击开启VPN开关

  • 若状态栏出现VPN图标，说明连接成功

可以通过访问被屏蔽的网站（如YouTube、Google）测试效果。

六、常见问题解答

Q1：小火箭打不开或下载不到怎么办？

A1：如App Store中搜索不到Shadowrocket，需切换Apple ID至海外（如美国、香港）账号才能下载。

Q2：连接不上怎么办？

A2：建议按以下顺序排查：

  • 检查网络是否通畅

  • 检查UUID、端口等是否填写错误

  • 切换协议类型（TCP ⇄ WS）

  • 尝试不同节点

Q3：Vmess链接失效了？

A3：Vmess服务本质是点对点代理，一旦服务商更换配置或服务器宕机，链接就会失效。应及时联系服务方更新配置。

Q4：使用Vmess安全吗？

A4：Vmess相较SS协议在协议伪装和传输加密方面更强，若搭配TLS/WS使用，隐私保护和抗干扰能力更高。

FAQ

Nekoray 能否同时运行多个代理？
Nekoray 支持多配置运行。用户可在“多配置模式”下同时开启不同协议或节点的代理，程序会自动创建多个监听端口，方便多应用或分流测试使用。
Clash 的自定义规则组能实现哪些功能？
Clash 的自定义规则组允许用户将多个节点和策略组合，通过优先级和条件分流流量。这样可以根据网站类别或流量类型自动选择最优节点，提高网络效率和使用体验。
如何在 Nginx 上为 Vmess/WS 配置反向代理与 TLS？
在 Nginx 中配置 HTTPS 站点并将特定路径（如 /ray）反向代理到 V2Ray 的 WebSocket 端口，确保 proxy_set_header 设置正确（Host、X-Real-IP 等）。同时使用 certbot 获取并自动续期 TLS 证书以维护安全。
Trojan TLS 如何避免被 DPI 检测？
通过选择真实可访问域名并使用有效证书，Trojan 流量可完全模拟 HTTPS 请求。隐藏真实流量特征，降低被封锁和 DPI 检测风险，保证节点长期可用。
Mellow 如何通过配置实现多出口分流？
Mellow 可在配置文件中定义多个 outbound，并结合 routing 规则实现按域名、IP 或策略组分流。这样不同类型的流量可走不同节点，提高使用体验。
Sing-box 如何实现精确端口分流？
Sing-box 支持按端口匹配流量，将不同类型应用流量分配到指定节点。结合策略组，可提高访问速度和网络稳定性，实现精准分流和优化用户体验。
PassWall2 如何定时自动更新节点？
可在计划任务中添加命令 `passwall update` 并设定时间间隔，例如每日凌晨自动更新。这样可确保节点信息实时同步，避免旧节点失效影响连接体验。
VLess 使用 XTLS 时证书怎么配置更安全？
推荐使用可信 CA 签发的证书（例如 Let's Encrypt），并为服务器配置正确的域名、SNI 与证书链。避免使用自签名证书或错误域名，以免被客户端拒绝或被中间人攻击检测到。
V2Ray 的 Reality 功能是什么？
Reality 是 V2Ray 新增的伪装技术，可替代传统 TLS。它无需真实证书，通过公钥验证机制实现端到端加密。相比 Trojan 的 HTTPS 伪装方式，Reality 更轻量、安全且配置更简洁。
SSR 的混淆方式如何选择最合适？
根据网络环境选择适合的混淆方式，如 tls1.2_ticket_auth 模拟 HTTPS 流量，可隐藏真实特征。结合协议插件使用，可以提高抗封锁能力和节点可用性。
